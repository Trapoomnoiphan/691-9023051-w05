# 🏎️ GT3 Racing Car Viewer

แอปพลิเคชัน Flutter สำหรับจัดเก็บและแสดงข้อมูลรถแข่งคลาส **GT3** ยอดนิยมจำนวน 6 รายการ โดยรองรับการแสดงผลรูปภาพหลายรูปต่อหนึ่งรายการ (Multi-Image Gallery) แยกตามโฟลเดอร์ของรถแต่ละคัน และมีระบบคลิกเพื่อดูรูปภาพขยายใหญ่เต็มหน้าจอที่สามารถใช้นิ้วย่อ-ขยายซูมได้ (Interactive Viewer)

---

## 📂 โครงสร้างโปรเจกต์ (Project Structure)

ซอร์สโค้ดและทรัพยากรต่าง ๆ ภายในโปรเจกต์ถูกจัดเก็บแยกสัดส่วนตามสถาปัตยกรรมของ Flutter ดังนี้:

```text
mb_id_w05/
├── assets/
│   └── images/              # โฟลเดอร์เก็บรูปภาพแยกตามรุ่นรถแข่ง (gt01 - gt06)
│       ├── gt01/            # รูปภาพของ Porsche 911 GT3 R
│       ├── gt02/            # รูปภาพของ Ferrari 296 GT3
│       ├── gt03/            # รูปภาพของ BMW M4 GT3
│       ├── gt04/            # รูปภาพของ Lamborghini Huracán GT3 EVO2
│       ├── gt05/            # รูปภาพของ Mercedes-AMG GT3 Evo
│       └── gt06/            # รูปภาพของ Aston Martin Vantage AMR GT3 Evo
├── lib/
│   ├── data/
│   │   └── gt3_car_data.dart         # ไฟล์คลังข้อมูลจำลองของรถแข่งทั้ง 6 คัน
│   ├── models/
│   │   └── gt3_car.dart              # โมเดลคลาสโครงสร้างข้อมูล (Data Model) ของ Gt3Car
│   ├── screens/
│   │   ├── gt3_car_detail_screen.dart # หน้าแสดงรายละเอียดข้อมูลและแกลเลอรีรูปภาพ
│   │   └── gt3_car_list_screen.dart   # หน้าจอหลักแสดงรายการรถแข่งทั้งหมดในรูปแบบ List
│   └── main.dart                     # จุดเริ่มต้นการทำงานของระบบ (Entry Point)
└── pubspec.yaml                      # ไฟล์สำหรับตั้งค่าโปรเจกต์และลงทะเบียนสิทธิ์ Assets
